# Waste Classification using CNN

A mini-project for classifying waste images into three categories:
Plastic, Paper, and Metal.

## Technologies Used

- Python
- TensorFlow / Keras
- EfficientNetB0
- Flask
- HTML, CSS, JavaScript

## Features

- Upload a waste image
- Predict the waste category
- Display prediction confidence
- Simple web interface

## Model

The project uses EfficientNetB0 with transfer learning and fine-tuning.

**Validation Accuracy:** ~97%

## Project Structure

- `app.py` – Flask application and model loading
- `index.html` – Web interface
- `style.css` – Styling for the interface
- `script.js` – Frontend functionality
- `waste_classification_model.h5` – Trained classification model
- `AI_Training_Source_Code/` – Model training-related code
- `requirements.txt` – Python dependencies

## Project Type

This project was developed as a semester mini-project.
